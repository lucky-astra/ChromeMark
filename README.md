# ChromeMark · 图文收藏

一个 Manifest V3 Chrome 扩展，把网页中的句子和图片保存在本机素材库。侧边栏采用浅色极简与蓝色主色，适配 Chrome Side Panel。

## 视觉方向

- 延续设计稿 3 的浅色工具感：主色 `#4367ED`、底色 `#F7F9FC`、深蓝灰文字与细边框。
- 侧边栏使用单栏图文卡片，分类筛选放在顶部；编辑、备注、标签和来源收进保存面板，减少浏览时的干扰。
- 蓝色四格标记作为插件识别符，黄色星点作为灵感提示；界面字体使用系统字族，不从第三方加载字体。

## 使用方式

1. 打开 `chrome://extensions`，启用「开发者模式」。
2. 选择「加载已解压的扩展程序」，选中本目录 `ChromeMark`（需要 Chrome 116 或更新版本）。
3. 点击工具栏扩展图标打开侧边栏。`Alt + M` 打开快速调用面板；快捷键冲突时，可在扩展管理页的「键盘快捷键」中修改。
4. 网页划词和图片悬停按钮默认关闭。进入侧边栏「设置与数据」，启用「网页浮动收藏按钮」并授予网页访问权限后生效；文字和图片的右键收藏不需要此项授权。

## 已实现

- 选择网页文字后出现轻量收藏按钮；支持一键快速收藏和打开完整保存面板。
- 图片悬停收藏按钮及右键收藏图片；会尝试缓存不超过 12 MB 的 HTTP(S) 图片到 IndexedDB，失败时保留原图地址。
- 右键收藏选中文字、打开 Side Panel 与快速调用面板。
- 本地素材库支持文本/图片、分类、标签、备注、来源、搜索、类型/分类筛选、排序、星标、复制、编辑和删除。
- `Alt + M` 快速搜索；Enter 尝试插入当前输入框，Shift + Enter 复制；没有可用输入框时回退为复制。
- IndexedDB 保存收藏与缓存图片；`chrome.storage.local` 保存设置与分类。
- JSON 导出、合并导入与覆盖导入。

## 数据与权限说明

- 收藏记录默认只保存在本机，插件没有自建服务端。缓存或预览未缓存的远程图片时，浏览器会请求图片原站。
- 基础能力使用 `storage`、`sidePanel`、`contextMenus` 等扩展权限。网页悬浮按钮启用时才申请 `http://*/*` 和 `https://*/*` 可选权限，可在设置中关闭。
- JSON 备份包含文本、来源、分类、标签和图片地址等元数据；为避免生成过大的 JSON，不包含缓存图片二进制文件。超过大小限制、登录保护或临时 `blob:` 图片可能无法本地缓存；若之后原图地址失效，图片也可能无法显示。
- Chrome 内置页、Chrome Web Store 等受限页面不允许注入网页悬浮按钮；可尝试使用扩展右键菜单或侧边栏手动收藏。

## 目录

- `manifest.json`：MV3 权限、Side Panel 和 Alt+M 命令。
- `background.js`：Service Worker、右键菜单、收藏消息和快速插入。
- `content.js`：网页文字/图片悬浮收藏按钮。
- `db.js`：IndexedDB 数据与图片缓存。
- `panel.html`、`panel.css`、`panel.js`：素材库、保存面板、设置与数据管理。
- `quick.html`、`quick.css`、`quick.js`：键盘快速调用面板。
